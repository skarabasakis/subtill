# Repositories

This document outlines the repositories used in the project and the methods they expose.

For each method we document

- its name and signature
- the sql query it executes

The exposed methods align with the business logic of the operations
sepcified in the [operations](20261018-operations.md) document.

## Conventions

- **Go names.** Types in `internal/core/store` are plural collection nouns (`store.Subscriptions`, `store.Preferences`, `store.Tags`, …) with no `Repository` suffix. In this document, unqualified names such as `Subscriptions.Get` mean those store types. Singular names are reserved for derived domain models (`Subscription`, `Payment`) and `*Record` row types.
- **Types.** Repositories accept and return the `*Record` types from the operations document, never the derived domain models (`Subscription`, `Payment`). Derivation happens in the service layer, in Go. `SubscriptionFiltersDb` (`Name`, `Group`, `Tags`, `Status`) is applied in SQL by `Subscriptions.Count` and `ListAll`. Every other `SubscriptionFilters` field, and all sort, is applied in the service after derivation. Repository methods do not accept sort arguments.
- **Record changes required.** `BillingPeriodRecord` needs a `SubscriptionID` field, `ReminderRecord` needs an `IsTriggered` field, and two new record types are introduced: `SubscriptionWithAssociations` (a `SubscriptionRecord` plus `BillingPeriods []BillingPeriodRecord`) and `ExchangeRateRecord` (`Currency`, `Rate`, `ExchangeOn`).
- **Tags.** `SubscriptionRecord.Tags` is not stored in the `subscriptions` table. It is left empty by `Subscriptions.GetByName`, `GetById` and `ListAll`. It is filled by `WithAssociations` and `WithAssociationsA` (tags and billing periods loaded in the same query).
- **Not found.** `Get`* methods return the sentinel `ErrNotFound` (wrapping `sql.ErrNoRows`) when no row matches. `Update`* and `Delete*` methods return `rowsAffected`, so services can detect a missing row (e.g. `reminder_not_found`) without an extra read.
- **Nullable columns.** Empty strings are written as `NULL` (`NULLIF(:x, '')`) and `NULL` is read back as an empty string.
- **IDs.** UUID v7 IDs are generated by the service and passed in on insert.
- **Dates** are `time.Date` values, stored as `YYYY-MM-DD` text.

## Repositories

### Subscriptions

- func Count(filter *SubscriptionFiltersDb, currentDate time.Date) (count int, err error) - returns the number of all subscriptions matching the optional filter

```sql
SELECT COUNT(*)
FROM subscriptions s
WHERE 1=1
-- [SubscriptionFiltersDb clauses](#subscriptionfiltersdb-clauses) appended here
```

- func GetByName(name string) (subscription *SubscriptionRecord, err error) - gets a subscription by name (case-insensitive)

```sql
SELECT * FROM subscriptions WHERE name = :name
```

- func GetById(id string) (subscription *SubscriptionRecord, err error) - gets a subscription by id

```sql
SELECT * FROM subscriptions WHERE id = :id
```

- func ListAll(filter *SubscriptionFiltersDb, currentDate time.Date) (subscriptions []SubscriptionRecord, err error) - lists subscriptions matching the optional filte

```sql
SELECT s.id, s.name, s."group", s.notes, s.icon, s.url
FROM subscriptions s
WHERE 1=1
-- [SubscriptionFiltersDb clauses](#subscriptionfiltersdb-clauses) appended here
ORDER BY s.id DESC
```

- func WithAssociations(subscription SubscriptionRecord) (s SubscriptionWithAssociations, err error) - loads the tags and billing periods of a subscription record that was already read (e.g. `WithAssociations(GetById(id))`), in a single query. Tags and billing periods are aggregated into JSON arrays with `json_group_array` and decoded in Go. Each association is aggregated in its own subquery rather than through a join of both tables, which would multiply rows (tags x billing periods) and corrupt the arrays. Tags are ordered by `tag` and billing periods by `start_on`. A subscription without tags or billing periods yields `'[]'`.

```sql
SELECT
  (SELECT json_group_array(tag)
     FROM (SELECT tag FROM tags
            WHERE subscription_id = :id
            ORDER BY tag)) AS tags,
  (SELECT json_group_array(json_object(
            'id', b.id,
            'subscriptionId', b.subscription_id,
            'billingCurrency', b.billing_currency,
            'billingCost', b.billing_cost,
            'cost', b.cost,
            'frequency', b.frequency,
            'startOn', b.start_on,
            'endOn', b.end_on))
     FROM (SELECT * FROM billing_periods
            WHERE subscription_id = :id
            ORDER BY start_on) b) AS billing_periods
```

- func WithAssociationsA(subscriptions []SubscriptionRecord) (s []SubscriptionWithAssociations, err error) - same as `WithAssociations` for many records (e.g. `WithAssociationsA(ListAll(filter, currentDate))`), in a single query. The input IDs are bound as a JSON array `:ids`; each result row is paired with its input record by `id`, and the result keeps input order. An empty input returns an empty slice without running SQL.

```sql
SELECT s.id,
  (SELECT json_group_array(tag)
     FROM (SELECT tag FROM tags
            WHERE subscription_id = s.id
            ORDER BY tag)) AS tags,
  (SELECT json_group_array(json_object(
            'id', b.id,
            'subscriptionId', b.subscription_id,
            'billingCurrency', b.billing_currency,
            'billingCost', b.billing_cost,
            'cost', b.cost,
            'frequency', b.frequency,
            'startOn', b.start_on,
            'endOn', b.end_on))
     FROM (SELECT * FROM billing_periods
            WHERE subscription_id = s.id
            ORDER BY start_on) b) AS billing_periods
FROM subscriptions s
WHERE s.id IN (SELECT value FROM json_each(:ids))
```

- func Insert(subscription SubscriptionRecord) (err error) - inserts a subscription (tags are inserted separately with `Tags.Insert`)

```sql
INSERT INTO subscriptions (id, name, "group", notes, icon, url)
VALUES (:id, :name, NULLIF(:group, ''), NULLIF(:notes, ''), NULLIF(:icon, ''), NULLIF(:url, ''))
```

- func Update(subscription SubscriptionRecord) (rowsAffected int64, err error) - updates all metadata columns of a subscription (the service coalesces unchanged fields first)

```sql
UPDATE subscriptions
   SET name = :name, "group" = NULLIF(:group, ''), notes = NULLIF(:notes, ''),
       icon = NULLIF(:icon, ''), url = NULLIF(:url, '')
 WHERE id = :id
```

- func DeleteById(id string) (rowsAffected int64, err error) - deletes a subscription; its tags, billing periods and reminders are removed by `ON DELETE CASCADE`

```sql
DELETE FROM subscriptions WHERE id = :id
```

#### SubscriptionFiltersDb clauses

`Count` and `ListAll` take an optional `filter *SubscriptionFiltersDb` (defined in [operations](20261018-operations.md): `Name`, `Group`, `Tags`, `Status`) and a `currentDate time.Date`. A `nil` or zero filter adds no predicates. `currentDate` is bound as `:current_date` only when `filter.Status` is non-empty; the service passes local calendar today, the same date it uses to derive `Subscription.status`. The repository does not default it.

The `Count` and `ListAll` statements end their `WHERE` clause with `1=1`. The repository appends the partial statement below for each filter field that is set, in the order listed, and nothing for unset fields. Lists are bound as JSON arrays and read with `json_each`, so the statement shape does not depend on list length. Partials refer to the subscriptions table by the alias `s`.

- **Name.** Appended when `filter.Name.Value` is non-empty. `equals` compares against the `COLLATE NOCASE` column, so its unique index serves the lookup:

```sql
AND s.name = :name
```

`contains` is case-insensitive and needs no escaping of `%` or `_`; it cannot use an index:

```sql
AND instr(lower(s.name), lower(:name)) > 0
```

- **Group.** Appended when `filter.Group` is non-empty:

```sql
AND s."group" = :group
```

- **Tags.** Appended when `filter.Tags.Values` is non-empty. `any` (the default) probes the `UNIQUE (subscription_id, tag)` index; `t.tag` comparisons use `NOCASE`:

```sql
AND EXISTS (SELECT 1 FROM tags t
             WHERE t.subscription_id = s.id
               AND t.tag IN (SELECT value FROM json_each(:tags)))
```

`all` passes only when no requested tag is missing; duplicate input tags do not change the result:

```sql
AND NOT EXISTS (SELECT 1 FROM json_each(:tags) j
                 WHERE NOT EXISTS (SELECT 1 FROM tags t
                                    WHERE t.subscription_id = s.id
                                      AND t.tag = j.value))
```

- **Status.** Appended when `filter.Status` is non-empty. One correlated aggregate over the subscription's billing periods, using the `billing_periods (subscription_id)` index. Several requested statuses are combined with OR through `IN`:

```sql
AND (SELECT CASE
              WHEN MAX(b.start_on <= :current_date
                       AND (b.end_on IS NULL OR b.end_on > :current_date)) THEN 'ongoing'
              WHEN MAX(b.start_on > :current_date) THEN 'scheduled'
              ELSE 'ended'
            END
       FROM billing_periods b
      WHERE b.subscription_id = s.id) IN (SELECT value FROM json_each(:status))
```

The status rules follow [subscription derived fields](20261018-subscription-derived-fields.md): a subscription is `ongoing` when any billing period is ongoing on `:current_date`, otherwise `scheduled` when any billing period starts after it, otherwise `ended`. With no billing periods, `MAX` is `NULL` and the status is `ended`, matching the no-billing-periods corner case.


### Tags

- func ListUnique() (tags []string, err error) - lists the distinct tags in use across all subscriptions (tags differing only by case collapse into one, since the column is `COLLATE NOCASE`)

```sql
SELECT DISTINCT tag FROM tags ORDER BY tag
```

- func ListBySubscriptionID(subscriptionID string) (tags []TagRecord, err error) - lists the tags of a subscription

```sql
SELECT * FROM tags WHERE subscription_id = :subscription_id ORDER BY tag
```

- func Insert(tag TagRecord) (err error) - adds a tag to a subscription; idempotent, adding an existing tag is a no-op

```sql
INSERT INTO tags (id, subscription_id, tag)
VALUES (:id, :subscription_id, :tag)
ON CONFLICT (subscription_id, tag) DO NOTHING
```

- func DeleteBySubscriptionID(subscriptionID string) (rowsAffected int64, err error) - removes all tags of a subscription

```sql
DELETE FROM tags WHERE subscription_id = :subscription_id
```

- func DeleteBySubscriptionIDAndTag(subscriptionID string, tag string) (rowsAffected int64, err error) - removes one tag from a subscription (case-insensitive); removing a missing tag is a no-op

```sql
DELETE FROM tags WHERE subscription_id = :subscription_id AND tag = :tag
```

### BillingPeriods

Bulk reads of billing periods across all subscriptions go through `Subscriptions.WithAssociationsA`, so there is no `ListAll` here.

- func ListBySubscriptionID(subscriptionID string) (billingPeriods []BillingPeriodRecord, err error) - lists the billing periods of a subscription, oldest first (uses the `subscription_id` index)

```sql
SELECT * FROM billing_periods WHERE subscription_id = :subscription_id ORDER BY start_on
```

- func GetById(id string) (billingPeriod *BillingPeriodRecord, err error) - gets a billing period by id

```sql
SELECT * FROM billing_periods WHERE id = :id
```

- func Insert(billingPeriod BillingPeriodRecord) (err error) - inserts a billing period

```sql
INSERT INTO billing_periods (id, subscription_id, billing_currency, billing_cost, cost, frequency, start_on, end_on)
VALUES (:id, :subscription_id, :billing_currency, :billing_cost, :cost, :frequency, :start_on, NULLIF(:end_on, ''))
```

- func Update(billingPeriod BillingPeriodRecord) (rowsAffected int64, err error) - updates all columns of a billing period except its id and subscription (the service coalesces unchanged fields first). Also used to set or clear `end_on` (cancel, resume, ending the current period on restart)

```sql
UPDATE billing_periods
   SET billing_currency = :billing_currency, billing_cost = :billing_cost, cost = :cost,
       frequency = :frequency, start_on = :start_on, end_on = NULLIF(:end_on, '')
 WHERE id = :id
```

- func UpdateCostById(id string, cost string) (rowsAffected int64, err error) - updates only the cost in the database preferred currency, used when the preferred currency changes and costs are recalculated

```sql
UPDATE billing_periods SET cost = :cost WHERE id = :id
```

- func DeleteById(id string) (rowsAffected int64, err error) - deletes a billing period

```sql
DELETE FROM billing_periods WHERE id = :id
```

### Reminders

- func ListAll() (reminders []ReminderRecord, err error) - lists all reminders

```sql
SELECT * FROM reminders
```

- func ListBySubscriptionID(subscriptionID string) (reminders []ReminderRecord, err error) - lists the reminders of a subscription

```sql
SELECT * FROM reminders WHERE subscription_id = :subscription_id ORDER BY trigger_on
```

- func GetById(id string) (reminder *ReminderRecord, err error) - gets a reminder by id

```sql
SELECT * FROM reminders WHERE id = :id
```

- func Insert(reminder ReminderRecord) (err error) - inserts a reminder

```sql
INSERT INTO reminders (id, subscription_id, action, custom_note, trigger_on, is_triggered)
VALUES (:id, :subscription_id, :action, NULLIF(:custom_note, ''), :trigger_on, :is_triggered)
```

- func Update(reminder ReminderRecord) (rowsAffected int64, err error) - updates the mutable columns of a reminder. Used to snooze (new `trigger_on`, `is_triggered = 0`) and to record that a notification was sent (`is_triggered = 1`)

```sql
UPDATE reminders
   SET action = :action, custom_note = NULLIF(:custom_note, ''),
       trigger_on = :trigger_on, is_triggered = :is_triggered
 WHERE id = :id
```

- func DeleteById(id string) (rowsAffected int64, err error) - deletes (clears) a reminder

```sql
DELETE FROM reminders WHERE id = :id
```

- func DeleteBySubscriptionIDAndAction(subscriptionID string, action ReminderAction) (rowsAffected int64, err error) - deletes all reminders of a subscription with the given action (used to delete "cancel" reminders)

```sql
DELETE FROM reminders WHERE subscription_id = :subscription_id AND action = :action
```

The methods below support the desktop reminder notifications and badge. They are not used by any operation.

- func ListUntriggeredDue(asOf time.Date) (reminders []ReminderRecord, err error) - lists reminders that are due on or before `asOf` and whose notification has not been sent

```sql
SELECT * FROM reminders WHERE trigger_on <= :as_of AND is_triggered = 0 ORDER BY trigger_on
```

- func CountDue(asOf time.Date) (count int, err error) - counts reminders due on or before `asOf` (uses the `trigger_on` index)

```sql
SELECT COUNT(*) FROM reminders WHERE trigger_on <= :as_of
```

### ExchangeRates

- func Get(currency string, exchangeOn time.Date) (rate *ExchangeRateRecord, err error) - gets the cached rate for a currency on an exact date. Weekend and holiday rolling is handled by the online source, so the cache is keyed by the requested date

```sql
SELECT * FROM exchange_rates WHERE currency = :currency AND exchange_on = :exchange_on
```

- func Upsert(rate ExchangeRateRecord) (err error) - caches a rate, replacing any existing rate for the same currency and date

```sql
INSERT INTO exchange_rates (currency, rate, exchange_on)
VALUES (:currency, :rate, :exchange_on)
ON CONFLICT (currency, exchange_on) DO UPDATE SET rate = excluded.rate
```

- func DeleteAll() (rowsAffected int64, err error) - truncates the cache, used when the preferred currency changes

```sql
DELETE FROM exchange_rates
```

### Preferences

- func Get() (preferences *PreferencesRecord, err error) - gets the singleton preferences row

```sql
SELECT currency, currency_conversion_mode FROM preferences WHERE id = 1
```

- func Upsert(preferences PreferencesRecord) (err error) - stores the preferences, creating the singleton row if it does not exist (database creation) or replacing its values (the service coalesces unchanged fields first)

```sql
INSERT INTO preferences (id, currency, currency_conversion_mode)
VALUES (1, :currency, :currency_conversion_mode)
ON CONFLICT (id) DO UPDATE
   SET currency = excluded.currency,
       currency_conversion_mode = excluded.currency_conversion_mode
```

## Atomicity and Transactions

Not shown in the signatures above: all repository methods accept
`q sqlx.Ext` as the first parameter. This is used to execute the sql query either directly or within a transaction.

Operations that perform more than one write run all their repository calls in a single transaction:

- `subscription.start`, `subscription.edit` and `subscription.cancel` (subscription, tags, billing periods and reminders are written together)
- `preferences.set`, which, when the currency changes, calls `BillingPeriods.UpdateCostById` for every billing period and, in live mode, `ExchangeRates.DeleteAll` followed by `Upsert` for each repopulated rate, so converted columns never mix currencies
